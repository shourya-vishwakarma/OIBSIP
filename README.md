# Number Guessing Game

## 📌 Project Overview

Number Guessing Game is a Java console-based game in which the computer randomly selects a number between 1 and 100.

The player gets 7 attempts to guess the correct number. After every wrong guess, the program gives a hint whether the guessed number is too high or too low.

## 🎯 Objective

The objective of this project is to create a simple interactive game using Java and practice basic programming concepts.

## ✨ Features

- Random number generation between 1 and 100
- 7 attempts for each round
- Higher or lower hints
- Displays remaining attempts
- Displays the correct number when all attempts are used
- Calculates the score
- Allows the player to play another round

## 🛠️ Technologies Used

- Java
- Scanner
- Random
