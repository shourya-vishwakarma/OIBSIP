# Java Task 2 - Number Guessing Game

## About the Project

This is a console-based Number Guessing Game developed using Java.

The computer randomly selects a number between 1 and 100, and the player has a limited number of attempts to guess the number.

## Features

- Random number generation
- User input using Scanner
- Maximum 7 attempts
- Higher/lower hints
- Score calculation
- Option to play again
- Game over message

## Technologies Used

- Java
- IntelliJ IDEA
- Java Scanner
- Java Random

## How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Open `NumberGuessingGame.java`.
4. Run the `main()` method.
